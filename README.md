## Агент печати  
Устанавливается на локальной машине.
Работает с принтерами через CUPS, по-умолчанию localhost:631.  
Опрашивает сервер на предмет заданий и отправляет их на печать, и возвращает статус печати задания.  
Передает на сервер список принтеров. 




### Настройка принтеров
Xprinter XP-365B

Настройка через CUPS  
Драйвер: `TSC TTP-244 Plus` 
Параметры по-умолчанию: Custom 43 * 25 mm (по размеру заправленной этикетки)
